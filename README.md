# 牙科器械再处理追溯台（hxwl-04）

口腔器械包「回收 → 清洗 → 灭菌 → 监测 → 放行 → 发放 → 召回」全链路追溯，纯前端、无后端。

## 技术栈

React 19 + Vite + TypeScript + CSS；数据保存在浏览器 localStorage，刷新后追溯链不丢。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104；`npm run build` 产物在 `dist/`，`npm run preview` 预览构建结果。

## 业务规则

- **器械包登记**：名称、包内器械、灭菌有效期天数。
- **清洗批次**：登记设备/登记人/时间与入批器械包；**同一器械包只能处于一个未结束批次**，使用归还后的包可再次进入再处理。
- **灭菌与三项监测**：灭菌后录入物理监测、化学监测、生物监测；**三项全部通过才放行**；任一失败立即**隔离整批**并列出影响范围（包清单与关联发放）。
- **放行发放**：登记椅位与发放时间；**按实际登记的发放时间**校验灭菌有效期——即使当前未过期，把发放时间填到有效期之后也会拒绝保存；锅次召回/隔离、状态非已放行同样拒绝，并实时给出拒绝原因。
- **按批次召回**：锅次标记召回、禁止再发放；**同锅次后续发放**（可选起始发放锚点）及全部未归还发放标记为**待追踪**，展示受影响记录并支持逐条确认。
- **追溯查询**：单包时间线展示登记 → 清洗 → 灭菌监测 → 放行/隔离 → 发放椅位 → 召回追踪。
- 空库时可一键**恢复演示数据**；也可清空或重置演示数据。

## 目录

- `src/types.ts` 领域模型
- `src/domain.ts` 业务规则纯函数（可被 Node 脚本直接验证）
- `src/demo.ts` 演示数据
- `src/store.tsx` Context + reducer + localStorage 持久化
- `src/views/` 各业务页签
- `scripts/verify-domain.mjs` 关键流程验证脚本（50 项断言）
- `scripts/verify-ui.mjs` 全部页签 SSR 渲染冒烟
- `scripts/verify-narrow.mjs` 窄屏（≤720px）卡片式表格静态复核

## 窄屏

宽度 ≤720px 时，各台账表格自动转为卡片式（字段名在左、值在右），无需左右拖动；≥721px 保持原表格布局。
